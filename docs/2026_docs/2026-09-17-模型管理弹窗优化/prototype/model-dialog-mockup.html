左侧锚点分区导航

基本信息 / 能力 / 参数 / 高级四大分区，点击定位，长表单一目了然。

参数分组 + 辅助说明

12 个参数按“采样 / 输出 / 惩罚 / 稳定性”分组，每个字段附中文用途提示。

3

能力卡片化

能力从复选框升级为图标卡片；开关改为“标题 + 说明”设置行。

4

互斥输入联动

Max Tokens 二选一分段器，未选中侧自动置灰，杜绝同时填写。

5

JSON 代码块化

高级 JSON 改为深色代码编辑风格，带格式校验状态角标。
