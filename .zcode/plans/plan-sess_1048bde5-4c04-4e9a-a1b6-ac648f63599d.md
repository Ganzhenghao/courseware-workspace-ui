## 目标

将提供商管理（ProviderDialog.vue，2 处）和模型管理（ModelDialog.vue，3 处）弹窗中的 JSON 输入，从纯文本 `el-input type="textarea"` 替换为基于 CodeMirror 6 的 `JsonEditor` 组件，支持：JSON 语法高亮、行号、语法错误实时标注（红色下划线 + 悬浮提示）、一键格式化、暗色主题跟随。

## 实施步骤

### 1. 新增依赖（更新 lockfile，属新增依赖场景）
```bash
pnpm add vue-codemirror codemirror @codemirror/lang-json @codemirror/lint @codemirror/theme-one-dark
```
均为 CodeMirror 6 生态轻量包（gzip 合计约 100~200KB）；无 postinstall 脚本，pnpm 10 无需额外放行。版本以安装时最新 6.x 为准。

### 2. 新建全局组件 `src/components/JsonEditor/index.vue`
按项目惯例局部引入（参考 HighCode）。设计：
- 基于 `vue-codemirror` 封装，props：`modelValue: string`、`placeholder`、`disabled`、`height`（默认约 120px）；emits：`update:modelValue`、`change`、`blur`
- extensions：`basicSetup` + `json()`（语法高亮 + 属性名补全）+ `jsonParseLinter()`（错误位置实时标注，与表单校验互补）
- 主题跟随暗色模式：读取 `useAppStore()` 的 `isDark`，暗色用 oneDark，亮色用默认主题
- 编辑器右上角悬浮「格式化」按钮：`JSON.parse` 成功后按 2 空格缩进回写；失败时 `ElMessage.warning('JSON 格式不正确，无法格式化')`
- 样式对齐 Element Plus：宽度 100%、边框/圆角用 `--el-*` 变量、聚焦态边框高亮

### 3. 改造 `src/modules/ai/views/provider/components/ProviderDialog.vue`
- 「连接扩展 JSON」中的附加请求头、附加查询参数 2 个 textarea 替换为 `JsonEditor`
- 通过 `@blur` 调用 `formRef.validateField(...)` 触发既有 rules（自定义组件不会自动触发 el-form 校验）；`validateJson` 规则与提交时 `JSON.parse` 逻辑保持不变

### 4. 改造 `src/modules/ai/views/model/components/ModelDialog.vue`
- 「附加请求 JSON」中的附加请求头、请求体、查询参数 3 个 textarea 替换为 `JsonEditor`，方式同上
